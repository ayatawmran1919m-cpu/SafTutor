# SafTutor UI/UX Guidelines

## Design Philosophy

SafTutor must have a premium, modern, and clean user interface that matches today's leading mobile applications.

## Target Users

- Students
- Parents
- Teachers
- Administrators

## Design Language

- Modern
- Premium
- Minimal
- Elegant

## Primary Colors

- Purple
- White

## Border Radius

Large rounded corners.

## Shadows

Soft shadows only.

## Icons

Modern rounded icons.

## Typography

Arabic-first interface (RTL).

Use modern Arabic fonts.

## Animations

Smooth transitions.

Fade animations.

Scale animations.

Micro interactions.

## Layout

Large spacing.

Clean cards.

No crowded screens.

Simple navigation.

## Mobile First

The application must be designed primarily for smartphones.

## Important Rule

Never use outdated dashboard designs.

Always follow modern mobile UI trends.
