# SafTutor User Roles

## 1. Parent (ولي الأمر)

Permissions:

- Register account
- Add students
- Book lessons
- Choose subjects
- Choose teachers
- View attendance
- View exam results
- View homework
- Track student progress
- Manage profile
- Receive notifications

---

## 2. Teacher (المعلم)

Permissions:

- Register account
- Wait for admin approval
- Manage availability
- Accept lesson bookings
- Start virtual classroom
- Upload homework
- Create exams
- Grade exams
- View schedule
- Manage profile

---

## 3. Administrator (الإدارة)

Permissions:

- Approve teachers
- Reject teachers
- Manage parents
- Manage students
- Manage teachers
- Manage bookings
- Manage subjects
- Manage educational stages
- Manage notifications
- Manage application settings
- View reports
- Manage subscriptions
